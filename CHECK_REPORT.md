## Архитектура RAG

### Правильная архитектура:
```
1. Пользователь вводит: бренд + запрос
2. DuckDuckGo собирает 10 источников по запросу
3. GigaChat анализирует контекст (без web_search)
4. Возвращает JSON с анализом бренда
5. Фронтенд показывает результаты
```

### Компоненты:

**search_collector.py:**
- `collect_search_results(query, max_results=10)` - сбор из DuckDuckGo
- `format_context(results)` - форматирование в текст
- `collect_and_format(query, max_results=10)` - объединенная функция

**gigachat_client.py:**
- `_call_gigachat(messages)` - вызов API (без web_search)
- `SYSTEM_PROMPT_ANALYZE` - промпт для анализа видимости бренда
- `analyze_brand_rag(brand, query, context)` - анализ бренда в контексте
- `check_brand(brand, query, context)` - главная функция проверки
- `_extract_json(text)` - парсинг JSON из ответа
- `_fallback_analysis(answer, brand)` - fallback если JSON не распарсен
- `_extract_brands_from_text(text)` - извлечение брендов через GigaChat

**main.py:**
- `/api/check` - endpoint для проверки бренда
- Автоматический сбор контекста через DuckDuckGo если не передан

### Ответ API:
```json
{
  "brand": "Demix",
  "query": "лучший бренд дешевых кроссовок",
  "mentioned": true,
  "position": 1,
  "role": "рекомендация",
  "reasoning": "Бренд упомянут первым в списке бюджетных кроссовок",
  "quotes": ["Demix - самые доступные технологичные кроссовки"],
  "mentioned_brands": ["Demix", "Anta", "Li-Ning", "Qutayma"],
  "rag": true
}
```

### Фронтенд показывает:
1. **Вердикт** - Бренд упомянут / Бренд не упомянут
2. **Мета-данные** - Позиция в топе (#1, #2...), Роль (рекомендация/сравнение/упоминание)
3. **Обоснование** - краткое объяснение от GigaChat
4. **Цитаты** - прямые цитаты из контекста
5. **Конкуренты** - список всех упомянутых брендов

## Как запустить:

```bash
cd backend
uvicorn main:app --reload --host 0.0.0.0 --port 8000
```

Затем открыть `index.html` в браузере.

## Тестирование:

1. Ввести бренд: `Demix`
2. Ввести запрос: `лучший бренд дешевых кроссовок`
3. Нажать "Проверить"
4. Ожидать результат (10-30 секунд)

Ожидаемый результат:
- Бренд упомянут: Да
- Позиция: #1-3
- Роль: рекомендация
- Конкуренты: Anta, Li-Ning, Qutayma и т.д.

## Отличия от старой системы:

❌ **Старая система:**
- GigaChat с `web_search=True` сам искал и отвечал
- Выдумывал источники и бренды
- Не контролировал что искать

✅ **Новая система (RAG):**
- DuckDuckGo собирает реальные источники
- GigaChat анализирует ТОЛЬКО предоставленный контекст
- Запрет на использование внешних знаний
- Требование цитат из контекста
