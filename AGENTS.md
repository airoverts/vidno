# AGENTS.md — инструкция для AI-ассистента (opencode)

## О проекте
**Vidno** — одностраничный сайт-продукт (лендинг + встроенный дашборд) для мониторинга видимости бренда в AI-ассистентах (ChatGPT, Claude, Perplexity и др.). Ванильные HTML/CSS/JS, без сборки и фреймворков. Графики — Chart.js (CDN). Анимации — AOS (CDN). Иконки — Font Awesome (CDN). Шрифт — Inter (Google Fonts).

## Структура файлов
- `index.html` — вся разметка (7 «страниц»: home, features, how, dashboard, pricing, resources, contacts + хедер/футер/модал/тост). Навигация SPA: переключение `.page.active`. Важно: в шаблонах встречаются inline-цвета и градиенты (превью фич, аватары команды/конкурентов, кейсы) — заданы через `style="background:..."` и хранятся в `js/script.js` в объектах-данных.
- `css/style.css` — единственный стилевой файл. Дизайн-токены в `:root` (строки ~22–59). Все цвета только через CSS-переменные. Тема одна (светлая), переключения темы нет.
- `js/script.js` — маршрутизация SPA, тема, бургер, модалы/тосты, дашборд (KPI, таблицы, графики Chart.js, рекомендации, конкуренты, рейтинг брендов), FAQ, ресурсы (блог/видео/кейсы/глоссарий), форма контактов, init AOS. Захардкоженные цвета: `chartColors()` (читает CSS-переменные), inline-цвета в датасетах (datasets графиков, `grad`-поля у COMPETITORS/FEATURE_DETAILS/BLOG_POSTS/VIDEO_TUTORIALS/CASES).
- `README.md` — описание.

## Как.colors — ДИЗАЙН-СИСТЕМА (чирнозовая)
Единственный источник цвета — эти HEX и CSS-переменные (`--accent`, `--night`, `--ok` и т.д.) в `css/style.css`. **Не вводить новые HEX.**

### Нейтральная база (≈75% интерфейса)
- `--bg`, `--bg-2`, `--surface` — `#FFFFFF` (карточки, контент)
- `--bg-soft` — `#EAF6F5` (мягкие секции, активный фон карты, KPI-заливки)
- `--bg-soft-2` — `#CFF3EF` (hover, тонкие заливки)
- `--text` — `#0B2B2F` (основной текст/заголовки)
- `--text-soft` — `#5B6B6D` (подписи, лейблы, вторичная копия)
- `--border` — `#E2E8E8` (все рамки, разделители, строки таблиц)
- `--surface-1` — `#4F6F6F` (боковые/верхние панели, чередование строк)
- `--night` — `#012533` (хедер, тёмные экраны, видео-фрейм, overlay модалки)

### Акцентный чирнозовый (≈15%)
- `--accent` — `#028090` (CTA, активные вкладки/навигация, заголовки разделов, бейдж «популярный», role-leader)
- `--accent-2`/`--accent-3` — `#008896` (иконки, второстепенные акценты, линии графиков, eyebrow)

### Функциональные статусы (≈10%, только для дельт/бейджей/критических значений)
- `--ok` — `#1D9E75` (положительная дельта, trend-up)
- `--warn` — `#5A7517` (нейтральная/плоская дельта, prio-med)
- `--bad` — `#2B4B4A` (отрицательная дельта, trend-down, prio-high)
- `--neutral` — `#888780` (без изменений, prio-low, role-none, неактив)

### Правило пропорций
75% нейтрально / 15% чирнозовый акцент / 10% статусы. Цвет — точечно, не заливать целые блоки (кроме разрешённых `#EAF6F5`/`#CFF3EF`). При избытке цвета — заменять на `#FFFFFF` или `#4F6F6F`.

## Конвенции и грабли
- **Два источника цвета.** CSS-переменные в `style.css` + захардкоженные HEX в `js/script.js` (графики Chart.js и `grad`-поля датасетов). При любой перекраске/правке цвета **всегда править оба файла**, иначе графики и превью останутся старой палитры.
- `grad`-поля в объектах COMPETITORS, FEATURE_DETAILS, BLOG_POSTS, VIDEO_TUTORIALS, CASES рендерятся через `style="background:${x.grad}"` — это linear-gradient из разрешённых HEX (см. объекты в начале `js/script.js`).
- Не добавлять **никаких комментариев** в код, если пользователь не просит.
- Не создавать doc/README файлы, если не запрошено.
- Не коммитить и не пушить без явного разрешения пользователя.
