# AGENTS.md — Vidno

## Проект

Vidno — лендинг и отдельный рабочий дашборд для мониторинга видимости бренда в AI-ответах. Основной пользователь — in-house маркетолог. Лендинг расположен в `index.html`, продуктовый интерфейс — в `dashboard.html`.

## Структура

- `index.html` — лендинг, SPA-навигация только для маркетинговых разделов.
- `dashboard.html` — отдельный рабочий интерфейс с левой панелью, live-проверкой и Планом роста.
- `css/style.css` — общий стилевой файл и дизайн-токены.
- `js/script.js` — логика лендинга.
- `js/dashboard.js` — навигация dashboard, localStorage, live-проверка и План роста.
- `backend/main.py` — FastAPI API.
- `backend/cache.py` — SQLite-кэш запросов и результатов.
- `backend/gigachat_client.py`, `backend/deepseek_client.py` — провайдеры модели.
- `backend/search_collector.py`, `backend/rag_analysis.py` — сбор источников и структурный анализ.

## Backend

- `GET /api/health` возвращает состояние провайдеров.
- `POST /api/check` принимает `brand`, `query`, `provider` и возвращает проверку AI-видимости.
- `POST /api/brief` формирует бриф только из подтверждённых данных рекомендации.
- `DELETE /api/cache` очищает кэш и защищён для удалённого вызова токеном.
- История интерфейса и сохранённые брифы находятся только в `localStorage`; сервер не хранит проекты или задачи.
- Для локальной разработки frontend использует `http://localhost:8000/api`; при едином origin — `/api`.
- Настройки backend: `GIGACHAT_CLIENT_ID`, `GIGACHAT_CLIENT_SECRET`, `GIGACHAT_MODEL`, `DEEPSEEK_API_KEY`, `DEEPSEEK_MODEL`, `CORS_ORIGINS`, `CACHE_ADMIN_TOKEN`, `CHECKS_PER_MINUTE`, `MAX_CONCURRENT_CHECKS`.
- Никогда не читать, не печатать, не добавлять в код и не коммитить содержимое `backend/.env`, ключи или токены.

## Дизайн

Единственный источник цветов — токены в `css/style.css`. Не вводить новые HEX. Использовать светлую палитру Vidno в контенте и `--night` только для разрешённых тёмных поверхностей, включая левую панель рабочего dashboard. При изменении цвета проверить и CSS, и захардкоженные данные Chart.js/градиенты в JavaScript.

## Правила работы

- Не добавлять комментарии в код без запроса пользователя.
- Не создавать README или документацию без запроса пользователя.
- Не коммитить и не пушить без явного разрешения пользователя.
- Не запускать линтеры и typecheck автоматически.
- Не удалять backend-кэш, логи или окружение без явного запроса.
- Перед изменением dashboard проверять desktop и мобильный режим ≤768px; после изменения live-проверки учитывать успех, ошибку backend, ошибку провайдера и сохранение localStorage.
