ПОЛИТИКА ОБРАБОТКИ ПЕРСОНАЛЬНЫХ ДАННЫХ

1. Общие положения

Настоящая Политика обработки персональных данных (далее — «Политика») определяет порядок обработки и защиты персональных данных пользователей сервиса Vidno (далее — «Сервис»).

Политика разработана в соответствии с Федеральным законом от 27.07.2006 № 152-ФЗ «О персональных данных», иными применимыми нормативными правовыми актами Российской Федерации и определяет основные принципы, цели и условия обработки персональных данных пользователей.

Оператором персональных данных является:

Оператором персональных данных является Vidno.

далее — «Оператор».

Используя Сервис и предоставляя свои персональные данные, пользователь подтверждает, что ознакомился с настоящей Политикой.

2. Основные понятия

В настоящей Политике используются следующие понятия:

Персональные данные — любая информация, относящаяся прямо или косвенно к определенному или определяемому пользователю.

Обработка персональных данных — любое действие или совокупность действий с персональными данными, включая сбор, запись, систематизацию, накопление, хранение, уточнение, использование, извлечение, удаление и уничтожение.

Пользователь — физическое лицо, использующее Сервис.

Сервис Vidno — программно-аппаратный комплекс, предоставляющий пользователю инструменты для анализа видимости брендов и компаний в ответах систем искусственного интеллекта.

3. Какие персональные данные мы можем обрабатывать

В зависимости от используемых функций Сервиса Оператор может обрабатывать следующие данные пользователя:

  • адрес электронной почты;
  • имя и фамилию, если пользователь самостоятельно их предоставляет;
  • данные учетной записи;
  • сведения, необходимые для авторизации;
  • сведения о компании и должности, если пользователь самостоятельно их предоставляет;
  • IP-адрес;
  • сведения о браузере, операционной системе и устройстве;
  • сведения о дате и времени использования Сервиса;
  • технические идентификаторы и журналы действий;
  • сведения о настройках и использовании учетной записи;
  • иные данные, которые пользователь добровольно предоставляет Оператору.

Оператор не запрашивает у пользователя специальные категории персональных данных, если иное прямо не предусмотрено отдельной функцией Сервиса.

Пользователю не следует передавать через Сервис сведения, которые не требуются для его работы, включая паспортные данные, сведения о здоровье, банковские реквизиты, пароли и иные особо чувствительные сведения.

4. Цели обработки персональных данных

Персональные данные обрабатываются для следующих целей:

  • регистрации и создания учетной записи пользователя;
  • предоставления доступа к Сервису;
  • идентификации и авторизации пользователя;
  • обеспечения безопасности учетной записи;
  • технического обеспечения работы Сервиса;
  • предоставления пользователю функциональности Vidno;
  • обработки обращений пользователей;
  • направления сервисных уведомлений;
  • улучшения качества, стабильности и безопасности Сервиса;
  • анализа посещаемости страниц через Яндекс Метрику после согласия пользователя;
  • предотвращения злоупотреблений, мошенничества и нарушений условий использования;
  • исполнения договоров с пользователями;
  • выполнения обязанностей, установленных законодательством Российской Федерации.

Оператор не использует персональные данные пользователя для целей, несовместимых с указанными в настоящей Политике, без получения необходимого правового основания или отдельного согласия пользователя.

5. Особенности обработки данных при использовании AI-функций Vidno

Vidno использует внешние системы искусственного интеллекта для обработки запросов и формирования результатов анализа.

Vidno не добавляет сведения учётной записи пользователя в запросы к AI-провайдерам. Введённый пользователем текст передаётся провайдерам и может содержать персональные данные.

При выполнении AI-запросов из Vidno внешним системам искусственного интеллекта передаются только необходимые для выполнения запроса данные, в частности:

  • текст соответствующего промта;
  • внутренняя инструкция Vidno по обработке запроса;
  • технические параметры, необходимые для выполнения запроса.

Vidno не добавляет в запрос автоматически следующие сведения учётной записи пользователя:

  • email пользователя;
  • пароль;
  • данные учетной записи;
  • IP-адрес пользователя;
  • персональные контактные данные;
  • сведения о профиле пользователя;
  • иные сведения учётной записи пользователя.

6. Правовые основания обработки

Обработка персональных данных осуществляется Оператором на основании:

  • согласия пользователя на обработку персональных данных;
  • необходимости обработки для заключения и исполнения договора с пользователем;
  • необходимости исполнения обязанностей Оператора, установленных законодательством Российской Федерации;
  • иных оснований, предусмотренных законодательством Российской Федерации.

7. Способы обработки персональных данных

Оператор осуществляет обработку персональных данных автоматизированным, неавтоматизированным и смешанным способами.

При обработке персональных данных Оператор может осуществлять:

  • сбор;
  • запись;
  • систематизацию;
  • накопление;
  • хранение;
  • уточнение;
  • извлечение;
  • использование;
  • удаление;
  • уничтожение.

8. Хранение персональных данных

Персональные данные хранятся в течение срока, необходимого для достижения целей их обработки, либо в течение срока, установленного законодательством Российской Федерации.

После достижения целей обработки или прекращения соответствующих правовых оснований персональные данные подлежат удалению или уничтожению, если их дальнейшее хранение не требуется законодательством Российской Федерации.

9. Передача персональных данных третьим лицам

Оператор не продает, не предоставляет и не распространяет персональные данные пользователей в целях, не предусмотренных настоящей Политикой.

Передача персональных данных третьим лицам допускается только:

  • с согласия пользователя, если такое согласие требуется;
  • когда передача необходима для исполнения договора с пользователем;
  • когда передача необходима для исполнения требований законодательства Российской Федерации;
  • в иных случаях, прямо предусмотренных законодательством Российской Федерации.

Внешние AI-сервисы получают текст запроса пользователя и внутренние инструкции, необходимые для выполнения AI-запроса. Сведения учётной записи Vidno не добавляет в запрос автоматически; введённый пользователем текст может содержать персональные данные.

После согласия на аналитические cookie Яндекс Метрика получает технические данные о посещении страниц, включая адрес страницы, источник перехода и параметры браузера. Вебвизор включён на публичных страницах и выключен в личном кабинете. Vidno не передаёт в Метрику сведения учётной записи, тексты промптов и ответы моделей через дополнительные события или параметры.
